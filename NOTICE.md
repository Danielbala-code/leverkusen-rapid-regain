# Data attribution and publication boundary

This repository analyses the Impect Bundesliga 2023/24 Open Data release. Impect is credited as the data provider.

No Impect raw data, event files, derived event-level tables, provider documentation, logos, or provider models are included here. Anyone wishing to reproduce the analysis must obtain the data independently from https://github.com/ImpectAPI/open-data and accept the applicable Impect terms.

The MIT License in this repository applies only to original code and prose created for this project. It does not license, transfer, or override rights in any Impect material.

This repository is for research and portfolio communication. It should not be treated as a redistribution mechanism for the underlying data.
